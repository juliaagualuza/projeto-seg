Análise Temporal e Espacial da Criminalidade no Estado do Rio de Janeiro (2014–2026)

Projeto da disciplina Linguagem de Programação — Análise e Visualização de Dados com Python

Resumo

Este trabalho propõe uma análise exploratória temporal e espacial dos registros de ocorrências no Estado do Rio de Janeiro, utilizando dados municipais mensais disponibilizados pelo Instituto de Segurança Pública (ISP-RJ). O recorte contempla os anos de 2014 a 2026, observando-se que 2026 contém somente os meses de janeiro a setembro na versão da base utilizada. A metodologia envolve leitura da planilha oficial, padronização de nomes de colunas, remoção de registros duplicados, agregações por ano, município e região e elaboração de visualizações com Python. Os resultados preliminares indicam variação no volume anual de registros, com aumento expressivo nos anos mais recentes do período completo. A distribuição espacial também é concentrada: a capital apresenta o maior total acumulado entre os municípios. Ressalta-se que os números representam contagens absolutas de registros, não taxas populacionais nem quantidade de vítimas únicas. A análise busca demonstrar como técnicas de ETL e análise exploratória podem apoiar a compreensão de padrões agregados, sem atribuir causalidade às variações observadas.

Palavras-chave: Segurança pública; análise exploratória; Python; dados abertos; Rio de Janeiro.

1. Introdução

A disponibilidade de dados públicos permite investigar a distribuição e a evolução dos registros de segurança pública. Entretanto, a interpretação exige atenção à unidade de medida, à cobertura temporal e às diferenças entre municípios. Este estudo utiliza a base municipal mensal do ISP-RJ para organizar e explorar esses registros.

As perguntas de pesquisa são: (RQ1) como evoluíram os registros anuais entre 2014 e 2025? (RQ2) quais municípios concentram os maiores totais no período? (RQ3) como os registros se distribuem entre as regiões do estado?

2. Metodologia

Foi utilizada a planilha municipal mensal publicada pelo ISP-RJ. O processamento é realizado em Python, com a biblioteca Pandas. O ETL lê a planilha, padroniza os nomes das colunas, remove linhas duplicadas e exporta os dados tratados em CSV. A análise exploratória agrega os registros por ano, município e região.

Limitação temporal: 2026 contém apenas janeiro a setembro na base analisada e, portanto, não é diretamente comparável aos anos completos. As contagens também não são ajustadas pelo tamanho da população.

Entre os municípios, os maiores totais acumulados informados pela agregação realizada foram: Rio de Janeiro (4.991.884), Duque de Caxias (479.931), São Gonçalo (473.700), Nova Iguaçu (427.304) e Niterói (368.506). Esses valores são contagens absolutas e refletem também diferenças de população e volume de registros.

Na distribuição regional, os totais observados foram: Capital (4.991.884), Interior (2.288.679), Baixada Fluminense (1.917.625) e Grande Niterói (944.876).

Os resultados descrevem os dados disponíveis e não permitem, isoladamente, concluir causas para as variações. Para comparações de risco entre municípios, seria necessário incorporar denominadores populacionais e calcular taxas.

4. Conclusão

A análise demonstra a utilidade de um fluxo reproduzível de ETL e de agregações exploratórias para investigar a evolução e a distribuição municipal dos registros de ocorrências. Como próximos passos, recomenda-se incorporar dados populacionais oficiais, calcular taxas por 100 mil habitantes, aprofundar a análise mensal e validar cada indicador segundo as notas metodológicas do ISP-RJ.

5. Reprodutibilidade e princípios FAIR

O código de processamento, o dicionário de dados e este artigo estão organizados no repositório. Para reproduzir: instale as dependências com pip install -r requirements.txt, coloque a planilha oficial em data/raw/BaseMunicipioMensal.xlsx e execute python src/etl.py. Os dados têm origem identificada, as variáveis são documentadas e o processamento é automatizado. A planilha original não é redistribuída neste pacote.
